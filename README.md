## 🚀 Proyek Unggulan

1. **HiVMate: Ekosistem Digital Pendukung Kesehatan**
   - 🏆 *Juara 1 Best Presenter Seminar Nasional SAINTEK III 2024*
   - Aplikasi deteksi & prediktif kepatuhan terapi berbasis Python & Streamlit.
   - [Live Demo Streamlit](https://hivmateteam19.streamlit.app/)

2. **Analisis Volatilitas Return Saham BBRI dengan Model EGARCH (Skripsi)**
   - Pemodelan deret waktu ekonometrika keuangan dengan model EGARCH (Nelson, 1991) menggunakan bahasa R (`rugarch`) untuk menangkap efek leverage & asimetri return saham perbankan.

3. **Kabupaten Lampung Timur dalam Angka 2024 (Publikasi BPS)**
   - Kompilasi, kurasi, dan audit kualitas data statistik resmi lintas 24 kecamatan.

4. **Sistem Deteksi Kecurangan (Fraud Detection) Survei**
   - Penerapan machine learning unsupervised anomaly detection (*Isolation Forest* & *Z-Score*) untuk menyaring data palsu survei lapangan.

5. **Infografis Visualisasi Program Desa Cantik (Desa Cinta Statistik)**
   - Data storytelling & desain informasi publik untuk aparatur desa.

## 🛠️ Tech Stack & Fitur Web

- **Frontend:** HTML5, Modern CSS3 (Cyber-Glassmorphism, CSS Grid, Flexbox, Keyframe Animations), Vanilla JavaScript (Zero Dependencies).
- **Interactive Features:**
  - ✨ Animated Star Constellation Particle Canvas.
  - 🔄 Dynamic typing animation untuk peran profesi.
  - 📊 Live interactive counters untuk statistik IPK & proyek.
  - 📁 3 Tab Direktori Portofolio (*Projects, Certificates, Awards*).
  - 🔍 Kategori filter proyek & keahlian interaktif.
  - 📑 Modal pop-up dialog untuk detail metodologi setiap proyek.
  - 📋 1-Click Copy Alamat Email dengan toast notification.
  - 📱 100% Mobile Responsive dengan drawer navigation.
